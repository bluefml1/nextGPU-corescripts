NextGPU.exe is not in git (built on Windows).

On a Windows machine with .NET 8 SDK installed, from repo root run:

  apps\NextGPU\build-publish.bat

That creates:
  - apps\NextGPU\publish\NextGPU.exe  (self-contained, no .NET needed to run)
  - NextGPU.exe at repo root

Then double-click NextGPU.bat at repo root.
